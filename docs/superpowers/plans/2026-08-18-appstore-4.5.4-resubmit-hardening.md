# App Store Resubmission Hardening (3.1.2 + 2.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conclusively remove the two remaining likely-rejection risks before resubmitting build 1.0(3): the paywall's missing auto-renewable-subscription disclosure (Guideline 3.1.2) and the dead "Sponsored" detail CTA button (Guideline 2.1).

**Architecture:** Two isolated SwiftUI view edits. (1) `PaywallView` gains a conditional legal-disclosure caption shown for auto-renewing plans (hidden for the one-time Lifetime). (2) `SponsoredDetails` drops its no-op call-to-action button so the expanded sponsor card is a pure information surface with no dead controls. No model, networking, StoreKit, or DB changes.

**Tech Stack:** SwiftUI (iOS 26), Swift 6 (`-default-isolation=MainActor`), RevenueCat (`PurchasesManager`/`SubOption`), xcodebuild (iphonesimulator), Argent MCP for optional live verification (sim: iPhone 17 Pro).

### Task 1: Paywall auto-renewable subscription disclosure (Guideline 3.1.2)

**Files:**
- Modify: `Places/Views/Paywall/PaywallView.swift`

**Interfaces:**
- Consumes: `selectedId: String?` (existing `@State`), `purchases?.subscriptions` (`[SubOption]`), the Lifetime id sentinel `"$rc_lifetime"` (already used by `ctaTitle`, `PaywallView.swift:215`).
- Produces: nothing consumed elsewhere — purely additive view state.

- [ ] **Step 1: Add the `selectedIsSubscription` computed property**

Insert directly above `private func ensureSelection()` (currently `PaywallView.swift:220`), inside the `// MARK: Actions` region or just before it:

```swift
    /// True unless the one-time Lifetime option is selected. Drives whether the
    /// auto-renewal disclosure is shown (Lifetime is a non-consumable, not a sub).
    private var selectedIsSubscription: Bool {
        guard let id = selectedId else { return true }
        return id != "$rc_lifetime"
    }
```

- [ ] **Step 2: Add the disclosure view**

Insert a new `// MARK:` section immediately after the `featureCard` computed property block (after `PaywallView.swift:112`, before `// MARK: Plans`):

```swift
    // MARK: Legal disclosure (App Review 3.1.2 — auto-renewable subscriptions)

    private var subscriptionDisclosure: some View {
        Text("Subscriptions renew automatically. Your Apple Account is charged at confirmation of purchase and again within 24 hours before each period ends, unless you cancel at least 24 hours before the current period ends. Manage or cancel anytime in Settings → Apple Account → Subscriptions.")
            .font(.system(size: 11, design: .rounded))
            .foregroundStyle(.secondary)
            .multilineTextAlignment(.center)
            .fixedSize(horizontal: false, vertical: true)
    }
```

